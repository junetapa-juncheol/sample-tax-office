# 온결숲 세무회계

가상 업체 포트폴리오 샘플입니다. 실제 업체의 영업·상담·모집·서비스가 아닙니다.

세무회계 사무소를 가정한 5쪽 소개 홈페이지. 차분한 녹색과 정리의 단계를 표현한 기하 도해를 사용합니다.

## 쪽 목록

- `index.html` — 첫 화면
- `about.html` — 사무소 소개
- `services.html` — 서비스
- `faq.html` — 자주 묻는 질문
- `contact.html` — 문의 과정 체험

## 기능 체험

문의 화면에서 예시 채우기 → 필수 항목과 동의 확인 → 결과 확인. 실제 전송·저장·상담은 없습니다. FAQ는 질문을 눌러 펼칠 수 있습니다.

## 로컬 실행

이 저장소 폴더에서 다음 명령을 실행합니다. 별도 설치나 빌드가 필요하지 않습니다.

```sh
python -m http.server 8000 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8000/`를 엽니다. 서버 포트가 사용 중이면 다른 포트를 지정합니다. 파일을 직접 더블클릭하기보다 HTTP 서버 사용을 권합니다.

## 사용 기술

HTML5 · CSS3 · Vanilla JavaScript · 직접 구성한 SVG/CSS 일러스트. 글꼴은 Google Fonts의 Noto Sans KR을 요청하며 글꼴 파일은 저장소에 포함하지 않습니다. 글꼴을 가져올 수 없으면 시스템 sans-serif를 사용합니다. 키보드 포커스·모바일 메뉴·움직임 줄이기 설정을 지원합니다. 분석 스크립트·외부 폼·결제 연동이 없습니다.
